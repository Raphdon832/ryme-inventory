# Ryme Inventory - Future Tools & Improvements Plan

This document outlines the planned improvements for existing tools and the introduction of new utility features to enhance business operations.

## 🧮 1. Calculator Improvements
- [x] **Calculation History (Ticker Tape)**: Record and display a scrollable list of recent operations. (NOW IN HAMBURGER MENU)
- [x] **Copy to Clipboard**: One-click icon to copy the current result for use in other forms.
- [x] **Tax/VAT Presets**: Dedicated buttons for adding/removing tax (configurable percentage).
- [x] **Profit Margin Tool**: Quick calculation of selling price based on cost and target margin.
- [ ] **Memory Functions**: Standard M+, M-, MR buttons for temporary value storage.

## 🛠️ 2. New Business Tools
- [x] **Unit Converter**: Quick conversions for interior design metrics (Inches to cm, ft to m, Sq Ft to Sq M).
- [x] **Currency Converter**: Real-time exchange rate calculations for imported goods.
- [x] **Barcode/QR Generator**: Create scannable tags for physical inventory items using SKUs.
- [x] **Quick Scratchpad**: A simple, persistent text area for temporary notes and dimensions. (AUTO-SAVES TO DEVICE)
- [x] **Markup & Discount Simulator**: View potential profit scenarios across different pricing strategies.
- [x] **Recent Tools Dashboard**: Dedicated section on home screen for one-tap utility access.

## 📈 3. Selected Business Upgrade Recommendations
- [ ] **Speed Up Order Creation**: Add draft autosave, recent customers/products, keyboard-friendly product search, faster customer selection, and duplicate/reorder shortcuts.
- [ ] **Strengthen Analytics**: Add monthly revenue/profit comparisons, customer purchase value, inventory value, dead stock detection, and clearer best-seller insights.
- [ ] **Improve Notifications**: Add an actionable notification center for low stock, overdue tasks, pending orders, unpaid invoices, and important stock/order changes.
